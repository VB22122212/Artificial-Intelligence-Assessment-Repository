# New Implementation Project

This is a simple Python project created as a fresh implementation task.

## Project idea
Build a small student management system that can:
- add a student
- view all students
- search by name or ID
- delete a student
- save data to a file

## Folder structure
- `app.py` - main program
- `student_manager.py` - logic for managing students
- `students.json` - saved student record
- `tests/test_student_manager.py` - sample tests

## Run
```bash
python app.py
```

## Test
```bash
python -m pytest
```
